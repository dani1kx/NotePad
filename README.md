# 📒 NotePad — Your Personal, Minimalist Note-Taking App

**NotePad** is a clean and simple web application for creating, editing, and organizing notes with a notebook-style design. Perfect for keeping all your ideas, plans, and tasks organized with a focus on simplicity and functionality.

## ✨ Features
- 🎨 **Minimalist Design** — Clean notebook grid background with semi-transparent notes
- 📝 **Note Creation** — Quickly add notes with title and content
- ✏️ **Inline Editing** — Edit notes directly with clean, consistent styling
- 📁 **Archiving** — Move completed notes to archive section
- 🔍 **Filtering** — View all notes, active only, or archived
- 💾 **Local Storage** — Notes persist even after page reload
- 📱 **Responsive Design** — Optimized for all devices (mobile, tablet, desktop)
- 🎯 **Markdown Support** — Format notes with markdown syntax

## 🚀 How to Use
- **Add Notes** — Enter title and content, then click "Add Note"
- **Edit Notes** — Click "Edit" button, modify content, then click "Save"
- **Archive/Unarchive** — Click "Archive" to move notes to archive or restore them
- **Delete Notes** — Use "Delete" button to permanently remove notes
- **Filter Views** — Use "All Notes", "Active", or "Archived" buttons to filter views

## 🛠️ Technologies
- **HTML5**
- **CSS3** with modern animations
- **Vanilla JavaScript** (ES6+) with jQuery
- **LocalStorage** for data persistence
